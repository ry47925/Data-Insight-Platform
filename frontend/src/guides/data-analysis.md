# 数据分析

数据分析模块帮助您快速掌握数据全貌：查看统计摘要、评估数据质量、绘制各类图表，并一键生成分析报告。

## 一、统计摘要

选择数据集后自动加载，包含三部分：

1. **基本信息**：总行数、总列数、数值列数、分类列数。
2. **列信息表**：每列的列名（可重命名）、类型（数值/分类，可点击切换）、缺失数、缺失率、完整性等级、唯一性等级、质量评分（0-100）。
   - 质量评分权重：完整性 60% + 唯一性 20% + 类型 20%。
3. **数值列统计**（16 项指标）：均值、中位数、标准差、最小值、最大值、缺失数、缺失率、偏度、峰度、P90/P95/P99、变异系数、众数、零值数、零值率。
4. **分类列统计**：唯一值数、缺失数、缺失率、TOP 值及频数。

## 二、数据质量概览

顶部质量卡片展示 5 个指标：

- 总体缺失率（缺失单元格 / 总单元格）
- 含缺失值列数
- 含无穷大列数（非 0 时标红提示，建议先在清洗模块处理）
- 重复行数
- 常量列数（唯一值数 ≤ 1）

三项核心指标全为 0 时提示"数据质量良好"。

## 三、图表分析（15 种）

图表按用途分为 4 组，选择图表类型后按提示选择对应列即可：

| 分组 | 图表 | 需要的数据条件 |
| --- | --- | --- |
| 数据分布 | 直方图、箱线图、KDE密度图、标准化QQ图 | 至少 1 个数值列 |
| 趋势与对比 | 面积图、多折线图、柱状图、堆叠柱状图、双Y轴图 | 数值列（柱状图需 1 分类+1 数值；双Y轴需 2 数值列） |
| 变量关系 | 散点图、气泡图、热力图、表格热力图 | 2 个以上数值列 |
| 占比构成 | 饼图 | 1 个分类列 |
| 特殊图表 | 雷达图 | 至少 3 个数值列 |

**常用参数**：

- 公共参数：显示数据标签、显示图例。
- 柱状/散点/面积：X 列（分类或留空用行索引）、Y 列（数值多选）、TOP N。
- 直方图/箱线图/KDE/QQ：数值列多选（直方图分箱数由后端按样本量自动计算）。
- 饼图：分类列 + TOP N（默认 10）。
- 热力图：数值列多选（默认全选计算相关性矩阵）。

> 选好图表后可点"**添加到分析报告**"，把该图表纳入后续生成的报告。

## 四、生成分析报告

点击"选择数据集"卡片标题栏的"生成分析报告"按钮，可勾选 6 个章节：

1. **数据预览**：预览行数（0-50，默认 5）
2. **数据质量概览**：可勾选各质量指标
3. **列信息**：全部列的类型/缺失/质量评分（固定展示）
4. **数值列统计**：可勾选 16 项统计指标
5. **分类列统计**：可勾选 4 项 + TOP 值数量（1-20，默认 10）
6. **自定义图表**：已"添加到分析报告"的图表

预览报告后可"**导出到数据管理**"保存为分析报告产物，供随时查看与下载。

## 五、使用建议

- 先看**质量概览**再决定是否清洗：缺失/无穷大/重复过高时，先去数据清洗模块处理。
- 分析"两列数值量纲差异大（>10 倍）"的关系时，推荐使用**双Y轴图**。
- 判断正态分布用 **QQ图**；看分布形态用**直方图/KDE**；看相关性用**热力图/散点图**。
- 报告生成 ≥1 万行时自动异步执行，可在任务面板查看进度。
