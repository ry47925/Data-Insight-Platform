# 特征工程

特征工程通过**构造新特征、编码、缩放、降维、选择**五大模块，把原始数据加工成更适合机器学习模型的特征。所有操作基于"列池"进行，执行后原地更新数据集，其他模块可立即使用新列。

## 一、五大模块

### 1. 特征构造（7 种操作）

| 操作 | 参数 | 说明 |
| --- | --- | --- |
| 四则运算 | 列1、运算符(+ - * /)、列2或常数 | 除法分母含 0 时拒绝构造 |
| 多项式 | 列、阶数(2-5) | 生成 `x²...xⁿ` 系列特征 |
| 对数变换 | 列 | `log1p(clip(0))`，负值裁剪为 0 并告警 |
| 分箱 | 列、箱数(2-20)、方法 | 等宽（按值域均分）/ 等频（按频数分箱） |
| 时间拆解 | 时间列、提取项 | year/month/day/weekday/quarter/is_weekend，每项生成一列 |
| 类别交叉 | ≥2 个类别列、分隔符 | 生成组合类别特征 |
| Target编码 | 类别列、数值目标列 | 用目标列按类别分组的均值替换 |

### 2. 特征编码

- **OneHot 独热编码**：生成 `ohe_{列}_类别` 系列 0/1 列。**高基数列上限 100**，超过会拒绝并建议改用 Label 编码或先分箱。
- **Label 标签编码**：生成 `le_{列}` 列，类别映射为整数 0,1,2...。

### 3. 特征缩放

- **StandardScaler 标准化**（前缀 `std_`）：均值 0、方差 1，适合距离类/梯度类算法（SVM、KMeans、神经网络等）。
- **MinMaxScaler 归一化**（前缀 `norm_`）：映射到 [0,1]，适合取值范围有限或对量纲敏感的算法。

> 执行缩放要求数据无无穷大/缺失值/常量列，建议先清洗。

### 4. 特征降维

- **PCA 主成分分析**：线性降维，输出各主成分解释方差比，适合特征冗余多时压缩维度。
- **t-SNE**：非线性降维，适合可视化（降维维度强制 ≤ 3）。

> 降维前会自动做标准化；建议先执行"特征缩放"再降维，效果更佳。

### 5. 特征选择（按评分选 Top-K）

| 方法 | 适用任务 | 原理 |
| --- | --- | --- |
| 卡方检验 chi2 | 仅分类 | 特征与目标独立性检验，特征需非负 |
| 互信息 mutual_info | 分类/回归 | 度量特征与目标的关联强度（默认推荐） |
| 皮尔逊相关 pearson | 回归 | 用相关系数绝对值排序 |
| 随机森林重要度 tree | 分类/回归 | 用模型特征重要性排序 |

选择目标列与 Top-K（默认 10）后，可"导出特征选择产物"生成新数据集。

## 二、列池管理

- 列按模块分组展示：原始列 / 特征构造 / 特征编码 / 特征缩放 / 特征降维。
- **删除**：仅构造列可删除，原始列禁止删除（防止破坏源数据）。
- **重命名**：原始列与构造列均可重命名。
- **导出列池**：按模块分组多选导出 CSV，作为特征工程产物。

## 三、预检建议

选择数据集后自动预检各列质量（类型、NaN、无穷大、常量、高基数列等），并给出操作可行性：

- 特征选择：存在可用数值列
- 特征构造：无硬性限制（有问题列时新列可能继承缺失值）
- 特征编码：存在非数值列；高基数列不建议 OneHot
- 特征缩放：存在可用数值列
- 特征降维：存在 ≥ 2 个可用数值列

## 四、使用建议

- 推荐顺序：**清洗 → 构造/编码 → 缩放 → 降维 → 选择**。
- 类别特征：低基数（≤ 100 类）优先 OneHot；高基数用 Label 编码或 Target 编码。
- 连续特征分布偏斜明显时，优先**对数变换**再缩放。
- 特征列多（> 500）时，先用**特征选择/降维**压缩，再训练模型，可显著提速。
- 特征工程产物会按模块分组保存在数据管理，供机器学习模块直接选择。
