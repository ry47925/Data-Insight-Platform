# 数据挖掘

数据挖掘模块提供三类经典任务：**聚类分析**、**关联规则**、**序列模式**，每类均有预检与算法推荐，帮助零基础用户也能快速上手。

## 一、三类任务

| 任务 | 用途 | 算法 |
| --- | --- | --- |
| 聚类分析 | 将样本划分为若干簇，发现数据内在分组 | KMeans、DBSCAN、层次聚类 |
| 关联规则 | 挖掘"买了 A 也买 B"的频繁共现模式（购物篮分析） | Apriori、FP-Growth |
| 序列模式 | 按时间顺序挖掘频繁发生的事件序列 | PrefixSpan、GSP |

## 二、算法参数说明

### 聚类分析

| 算法 | 参数 | 默认值 | 说明 |
| --- | --- | --- | --- |
| KMeans | 聚类数 n_clusters | 5（自动推荐） | 2-10 |
| | 初始中心 init | k-means++ | 也可选 random |
| | 最大迭代 max_iter | 300 | 100-1000 |
| | 运行次数 n_init | 10 | 1-20，越大结果越稳定 |
| DBSCAN | 邻域半径 eps | 0.5 | 0.01-10，越小簇越细 |
| | 最小样本 min_samples | 5 | 1-100 |
| | 距离度量 metric | euclidean | 可选 euclidean/manhattan/cosine |
| 层次聚类 | 聚类数 n_clusters | 3（自动推荐） | 2-10 |
| | 连接方式 linkage | ward | 可选 ward/average/complete/single |

> **自动推荐原理**：聚类数 K 综合**轮廓系数**（主）与**肘部法则**（辅）在 2 到 min(10, √行数) 中寻找最优；DBSCAN 的 eps 通过 **k-距离图拐点**确定，min_samples 按数据量分级（<100 行取 3、100-1000 行取 5、>1000 行取 10）。

### 关联规则

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 数据格式 | basket（购物篮） | basket 需选事务标识列+项列；binary 自动二值化 |
| 最小支持度 min_support | 0.1 | 0.01-1.0，支持度 = 项集出现次数 / 事务数 |
| 最小置信度 min_confidence | 0.8 | 0.5-1.0，置信度 = 条件概率 P(B|A) |
| 最小提升度 min_lift | 1.0 | >1 表示 A 与 B 正相关，越大越强 |
| 最大项集长度 | 不限制 | 1-10 |

> **自动推荐原理**：按事务数分级——<100 行建议 `支持度 0.2 / 置信度 0.8`；100-1000 行 `0.1 / 0.7`；>1000 行 `0.05 / 0.6`。

### 序列模式

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 最小支持度 min_support | 0.1 | 0.01-1.0 |
| 最大序列长度 max_len | 10 | 0 表示不限制 |

> **自动推荐原理**：按序列数分级——<50 个序列支持度 0.3；50-500 个 0.1；>500 个 0.05。

## 三、预检与算法推荐

选择数据集后自动预检，给出：

- **数据概况**：行数、列数、数值列/类别列数、缺失值比例、异常值比例（IQR 法）、时间列、ID 列。
- **阻断错误**：行数 < 3（样本过少）、无数值列（无法聚类）时阻止执行。
- **警告**：缺失率 > 30%、异常值比例 > 10%、列数 > 50、类别列唯一值 > 100（关联规则可能产生大量项集）。
- **算法推荐理由**：
  - KMeans：经典聚类算法，适用性广（始终推荐）
  - 层次聚类：行数 ≤ 2000 时推荐（数据量大时性能较差）
  - DBSCAN：行数 ≥ 50 或数值列 ≥ 3 时推荐（可发现任意形状的簇）
  - FP-Growth：数据量 ≥ 500 行时推荐（效率更高）
  - PrefixSpan / GSP：检测到时间列时均推荐

## 四、使用建议

- 聚类前建议先到清洗模块处理缺失值/异常值，并在特征工程做**特征缩放**（KMeans 基于距离）。
- 关联规则适合**高维稀疏**的"事务-商品"数据；类别列唯一值过多时会告警，可先筛选高频类别。
- 序列模式需要数据含**时间列**，且需明确序列标识列与事件列（也可自动检测）。
- 挖掘结果可预览、下载 CSV，也可保存为挖掘产物供特征工程/AI 分析使用。
