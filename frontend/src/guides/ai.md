# AI 分析

AI 分析模块让您以**自然语言对话**的方式与自己的数据交互。顶部 Tab 提供两种模式，定位不同：

| 模式 | 定位 | 适用场景 |
| --- | --- | --- |
| **分析对话** | 先"注入上下文"（选中真实数据产物/操作记录），AI 基于您的实际数据回答，而不是凭空猜测 | 数据诊断、训练排障、清洗配置分析 |
| **产品问答** | 面向"数据仓库"（勾选数据集或选择常驻目录）做精确问答与预测，AI 现算现答 | 统计、分组、筛选、趋势与预测 |

> **切换模式会清空已选上下文、输入框中未发送的内容和当前对话**，避免两个模式之间的数据串用。

## 一、分析对话（上下文注入）

页面顶部的"上下文注入"面板可选择两类上下文：

| 类型 | 内容 | 用途 |
| --- | --- | --- |
| **数据产物** | 原始数据、清洗产物、分析报告、挖掘产物、特征产物、机器学习产物 | 让 AI 基于真实数据回答（可预览摘要，选中数据产物会自动带出其血缘链上的操作） |
| **操作记录** | 各模块的历史任务（清洗/分析/挖掘/特征/ML 的训练与预测） | 帮助诊断训练参数、清洗配置等问题 |

**筛选功能**：搜索框（按名称/#ID）、类型（数据产物/操作记录）、状态（成功/失败）、模块、数据来源（本地/远程）。

使用方法：勾选需要的上下文项 → 输入问题发送 → 本次对话将注入 N 个上下文项。

## 二、产品问答（数据仓库精确问答）

在"数据仓库选择"区域选定本次分析的数据集，再提问即可：

- **选择数据**：可逐项勾选、一键全选所有数据产物，或直接装载已保存的**常驻目录**（保存为目录后可复用同一组数据集）。
- **本地精确计算**：统计（总数/均值/最值/标准差）、按列分组统计、筛选、列类型与缺失、数值分布/离群、模型预测等结果由系统**本地真实计算**得出，AI 再结合结果解读，不凭空猜测。
- **时间外推**：选中预测模型且数据含时间列时，可给出下一期（一段）趋势外推值。
- **无关问题拦截**：问题与所选数据集无关时，AI 会提示当前目录范围并引导补充勾选或选择目录。
- **引导补充分组**：含"按某列统计"意图但未指定列时，系统会返回候选低基数列并引导您选择。

## 三、对话能力

- **多轮对话**：同一话题内 AI 记住上下文；"开始新话题"可断开历史关联。
- **追问建议**：AI 回答后会提供追问问题，一键续问。
- **Token 消耗**：每条消息展示输入/输出/合计 Token 用量。
- **缺失上下文提示**：问题需要数据但未注入时，AI 会提示缺失的类型，按提示补充即可。
- **快捷模板**：空会话提供 4 条常用提问（两种模式各有专属模板）。
- 快捷键：**Ctrl + Enter** 发送。

## 四、会话管理

- 历史会话自动保存，按更新时间排序，支持**搜索**、**打开**、**重命名**、**删除**。
- 打开历史会话时，系统会根据会话类型**自动切换到对应模式**（产品问答/分析对话），并**恢复上次选中的上下文/数据集**，无需重新勾选。
- 若历史会话引用的数据集已被放入回收站、彻底删除、文件损坏，或任务记录已不存在，对应上下文项会用红色文字标注状态（如"已移至回收站""已彻底删除"），并弹窗提示可手动移除。
- "新建会话"不会删除后端历史记录。

## 五、使用统计

右上角"使用统计"弹窗展示 4 个指标：今日 Tokens、本周 Tokens、累计 Tokens、今日调用次数。

## 六、使用建议

- **想得到精准分析**：先勾选相关数据产物（AI 基于真实数据回答），并明确说明想解决的问题。
- **想排查训练问题**：注入机器学习模块的操作记录，AI 可帮助解读训练参数、指标与潜在问题。
- **想要现算的数字**：切到产品问答模式，勾选数据后直接询问统计/分组/预测，结果为系统真实计算。
- **模块联动**：AI 分析可以与数据清洗、特征工程、机器学习的产物/记录结合提问，形成"分析-清洗-建模"闭环。
- 若顶部显示"AI 服务不可用"，说明系统尚未配置 API Key，请联系管理员配置。
