# 操作历史

操作历史记录平台上的全部异步任务（上传、清洗、分析、挖掘、特征工程、机器学习、AI 对话等），支持多维筛选、详情查看、失败重试与任务取消。

## 一、筛选条件

| 筛选 | 选项 |
| --- | --- |
| 操作大类 | 文件上传 / 数据治理 / 数据清洗 / 数据分析 / 数据挖掘 / 特征工程 / 机器学习 / AI分析 / 账号管理 |
| 具体操作 | 与大类二级联动（如上传按来源模块、数据治理按删除/恢复/导入等） |
| 状态 | 成功 / 失败 / 运行中 / 等待中 / 已取消 |
| 数据来源 | 本地数据 / 远程数据库 |
| 时间范围 | 今天 / 近7天 / 近30天 / 自定义日期时间范围 |
| 关键字 | 按数据集名称搜索 |

> 从数据管理的"历史"按钮进入时，会自动携带该数据的 **dataset_id** 过滤，右上角标签可随时清除。

## 二、列表信息

- **操作类型**：大类标签 + 操作子类（如"数据清洗 · 执行清洗"），远程任务带远程标记。
- **操作对象**：本地显示数据集名/文件名，远程显示连接名/表名。
- **状态**：等待中 / 运行中 / 成功 / 失败 / 已取消（不同颜色标签）。
- **执行时间**：毫秒级格式化显示。
- **创建/完成时间**：以上海时区展示。

## 三、任务详情

点击"详情"查看抽屉面板：

- **基本信息**：操作类型、操作对象、状态、耗时、时间。
- **操作参数**：该任务的配置参数（过滤掉进度类字段），大字段自动折叠。
- **执行结果**：清洗的变动详情（字段：旧值 → 新值）、训练指标、预测结果等。
- **进度时间线**：阶段 + 进度百分比 + 阶段消息。
- **错误信息**：失败时展示错误信息与**失败分类**（参数错误 / 数据问题 / 系统故障 / 执行超时 / 网络错误 / 未知）。

## 四、重试与取消

- **重试**：仅失败任务且支持重试时可点（`can_retry`）。分类为"参数错误 / 数据问题"的任务**不支持重试**，需修改参数或数据后重新执行；"系统故障 / 超时 / 网络错误"可点击重试。
- **取消**：运行中/等待中的任务可取消。

## 五、使用建议

- 运行中的任务列表**每 10 秒自动刷新**，无需手动操作。
- 排查失败任务先看**失败分类**，再决定是改参数重跑还是直接重试。
- 大数据集（≥1 万行）的清洗/挖掘/建模均在此留痕，可随时回溯参数与结果。
