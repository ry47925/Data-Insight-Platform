# 数据清洗

数据清洗采用**五步向导**，引导您从"问题检测"到"清洗执行"再到"结果审计"，全程可视化，无需编写代码。

## 一、五步流程

| 步骤 | 名称 | 作用 |
| --- | --- | --- |
| 1 | 预检 | 自动检测缺失值、重复行、类型识别、异常值、类型错误 |
| 2 | 契约 | 为每列配置期望类型与范围/枚举/日期等约束 |
| 3 | 问题清单 | 按契约分析 6 类问题，逐条或批量设置处理方式 |
| 4 | 管道 | 自动生成清洗步骤，可调整顺序、追加列操作/行过滤 |
| 5 | 审计 | 前后对比、质量评分、行级差异，确认后保存结果 |

## 二、6 类问题及处理方法

在"问题清单"步骤中，每类问题可选的处理策略：

| 问题类型 | 处理策略（数值列 / 非数值列） |
| --- | --- |
| **缺失值** | 均值填充 / 中位数填充 / 众数填充 / 删除行 / 自定义值 / 标记列（新增"列_标记_缺失值"布尔列） |
| **类型错误** | 强制转换（默认：整数取整、数值按小数位四舍五入、日期转标准格式）/ 标记为缺失 / 删除行 |
| **范围错误** | 截断到上/下边界 / 截断到最近边界 / 删除行 / 标记 / 均值 / 中位数 / 自定义值 |
| **异常值** | 截断到 IQR 边界（默认）/ 均值 / 中位数 / 众数 / 删除行 / 标记 / 自定义值 |
| **行重复** | 保留第一条（默认）/ 保留最后一条 / 全部删除 |
| **列重复** | 保留第一条 / 保留最后一条 / 全部删除 / 手动选择保留行 |

> 每类问题都支持"批量设置：应用到全部"，避免逐列重复配置。

## 三、契约配置（第 2 步）

为每列设置期望类型与约束，作为问题判定的依据：

| 期望类型 | 可配置约束 |
| --- | --- |
| 整数 / 数值 | 范围约束（可多段）、小数位数 |
| 字符串 | 枚举值、最小/最大长度 |
| 布尔 | 布尔表示方式（0/1、是/否、true/false、True/False，默认 0/1） |
| 日期 | 最小/最大日期 |
| 邮箱 / 网址 | 仅校验格式 |
| 通用 | 是否允许缺失、是否允许重复 |

## 四、管道调整（第 4 步）

- 问题处理步骤**自动生成**，可拖拽/上移下移调整顺序。
- 支持追加**列操作**（重命名/删除列）与**行过滤**（条件式，如 `age > 18 & status == 'active'`，支持 `> < == != >= <=` 和 `& | !`）。
- 推荐执行顺序（后端校验依据）：

```
行重复 → 列重复 → 类型错误 → 范围错误 → 异常值 → 缺失值 → 列操作 → 行过滤
```

> **为什么缺失值最后处理？** 缺失值填充可能产生不符合类型要求、超出范围或异常的值；若先填充再处理类型/范围/异常值，会引入新的错误。反之先处理其他问题再填充，结果更干净。

**顺序与引用规则**：

- 列操作和行过滤必须位于管道末尾；列操作必须在行过滤之前，否则会**阻断执行**。
- 列重命名后，后续行过滤/列操作必须使用**新列名**，用旧列名写的条件不会生效。

## 五、执行前检查（dry-run）

点击执行清洗前，系统会先做预检：

- **错误（阻断）**：如"列操作在行过滤之后""行过滤引用已删除的列"，只能返回修改。
- **警告（可强制执行）**：如缺少必要操作、顺序问题、列引用冲突、数据丢失风险（累计删除可能超过 50% 数据、行过滤后数据量不足）。可在确认弹窗中选择"强制执行"或"返回修改"。

## 六、审计报告（第 5 步）

- 清洗摘要：原始/清洗后行列数、操作数、新增标记列数。
- **质量评分**（4 维度前后对比）：完整性（缺失）、唯一性（重复）、一致性（类型）、有效性（范围/异常值）。
- **行级差异**：展示每一行的问题类型、处理方法、原始值 → 修改后值。
- 确认后点击"保存清洗结果"，生成 `cleaning_result` 产物到数据管理。

## 七、使用建议

- **异常值检测原理**：默认采用 **IQR 方法**（四分位距），超出 `Q1 - 1.5×IQR` 至 `Q3 + 1.5×IQR` 视为异常值；数据少于 4 个时不检测。
- 布尔列支持是/否、0/1、true/false 等多种写法，未指定时按 0/1 处理。
- 清洗结果会自动写入算法描述；远程大表（>5 万行采样）只允许预览清洗结果，**禁止保存**，请先导入本地数据集再全量清洗。
