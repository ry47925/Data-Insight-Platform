# 数据管理

数据管理是平台的数据资产中心，集中展示**原始数据与各模块产生的全部产物**，并提供跨模块导入、数据血缘、回收站等功能。

## 一、产物类型（Tab）

左侧 Tab 按产物类型分组展示：

| Tab | 包含内容 |
| --- | --- |
| 原始数据 | 各模块上传的原始文件（可切换"来源模块"筛选） |
| 数据分析报告 | 数据分析模块生成的 HTML 报告 |
| 数据清洗产物 | 清洗后保存的结果数据 |
| 数据挖掘产物 | 聚类结果 / 关联规则 / 序列模式（可切换子类型筛选） |
| 特征工程产物 | 特征构造/编码/缩放/降维/选择后导出的数据集 |
| 机器学习产物 | 训练好的模型（.pkl）与训练报告（可导出 PDF） |
| 机器学习预测数据 | 上传的预测文件与批量预测结果 |
| 回收站 | 已删除（软删除）的数据，可恢复或永久删除 |

## 二、常用操作

每行数据根据类型提供不同操作：

- **预览**：查看数据内容。关联规则以支持度/置信度/提升度表格展示；数据分析报告以页面形式渲染。
- **下载 / 导出**：原始数据导出 CSV；机器学习模型导出 .pkl；报告导出 PDF / HTML。
- **血缘**：查看该数据的上游来源与下游衍生关系（同模块生成为实线，跨模块导入为虚线）。
- **编辑**：修改名称、标签（逗号分隔）、备注（≤200 字）。名称修改会同步到机器学习模块的已训练模型列表。
- **删除**：软删除，进入回收站；回收站中可**恢复**或**永久删除**（永久删除后用户端不可找回）。

> 同名数据集靠**色点 + #id** 区分，编辑名称时可参考右侧时间与行数信息。

## 三、跨模块导入

顶部"数据导入"可将已有产物复制到其他模块使用：

- 可导入的来源：原始数据、清洗产物、挖掘产物（聚类/关联/序列）、特征工程产物等。
- 目标模块：数据分析、数据清洗、数据挖掘、特征工程、机器学习、AI分析。
- 导入即创建一份副本，后续可在对应模块中直接选择使用。

## 四、数据源管理

点击右上角 **"数据源"** 按钮打开数据源管理弹窗：

- **本地数据集**：各模块上传后自动汇总。
- **远程数据库**：新建/编辑连接（目前支持 MySQL、PostgreSQL），配置连接名称、主机、端口、数据库名、用户名、密码及额外参数，可先"测试连接"再保存；"浏览表"可查看表名/行数/列数，并支持"在模块中使用"直接跳转到指定模块加载该远程表。

## 五、使用建议

- 上传文件统一在**各业务模块**内进行（数据分析/清洗/挖掘/特征/ML 页面的"数据上传"卡片），数据管理页负责统一查看与管理。
- 需要全量分析远程大表时，先在数据管理中把远程表**导入为本地数据集**，避免采样带来的误差。
- 删除是软删除，误删可在回收站恢复；永久删除与清空回收站不可在用户端找回。
