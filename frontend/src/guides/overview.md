# 平台总览

欢迎使用 **Data Insight 数据分析平台**。本平台面向从入门到进阶的所有用户，帮助您完成 **数据接入 → 数据治理 → 分析挖掘 → 特征建模 → 智能决策** 的全流程。以下先介绍几个贯穿全平台的通用概念。

## 一、数据从哪来

平台支持两类数据来源，各业务模块的数据源选择器都支持二者切换：

| 来源 | 说明 | 适用场景 |
| --- | --- | --- |
| **本地数据集** | 上传 CSV / Excel(.xlsx/.xls) / JSON 文件（单个最大 100MB） | 数据在本地、需要持久保存与分析 |
| **远程数据库** | 连接 MySQL / PostgreSQL，直接选取数据表分析（表超过 5 万行会自动随机采样） | 数据在业务数据库，避免重复导出 |

> 远程大表提示：表超过 **50000 行** 时，模块加载会自动随机采样 50000 行（随机起点连续片段）。如需全量分析，请先在数据管理中将远程表导入为本地数据集。

## 二、异步任务机制

大数据集（**≥1 万行**）的分析、清洗、挖掘、建模会自动转为后台异步任务执行：

- 任务提交后可在右上角**任务面板**实时查看进度（加载 20% → 处理中 50% → 评估 80% → 保存 100%）。
- 小数据集（<1 万行）同步执行，直接返回结果。
- 远程数据源强制同步执行。

## 三、推荐的完整工作流

根据首页提供的三条工作流路线，建议按需组合：

1. **纯挖掘线**：原始数据 → 数据清洗 → 数据挖掘 → 查看结果 → 辅助决策（无需建模）。
2. **建模预测线**：原始数据 → 数据清洗 → 特征工程 → 机器学习（训练 + 自动调优）→ 批量预测。
3. **组合增强线**：挖掘产物作为特征输入 → 特征工程 → 机器学习建模，效果通常更优。

通用顺序建议：**先清洗，再分析/挖掘，后建模**。清洗质量直接决定下游分析与建模效果。

## 四、模块导航

| 模块 | 主要用途 |
| --- | --- |
| 数据管理 | 查看/管理所有数据集与产物、数据血缘、回收站、跨模块导入 |
| 数据分析 | 统计摘要、数据质量概览、15 种图表可视化、生成分析报告 |
| 数据清洗 | 五步向导：预检 → 契约 → 问题清单 → 管道 → 审计 |
| 数据挖掘 | 聚类分析、关联规则、序列模式三类任务 |
| 特征工程 | 特征构造 / 编码 / 缩放 / 降维 / 选择，列池管理 |
| 机器学习 | 14 种算法训练、自动调优、批量预测 |
| AI分析 | 注入数据产物/操作记录上下文，进行智能对话分析 |
| 操作历史 | 查看全部异步任务记录，支持筛选、重试、取消 |

> 切换数据集后，各模块已填写的参数会重置为新数据集的默认状态，请留意重新配置。
