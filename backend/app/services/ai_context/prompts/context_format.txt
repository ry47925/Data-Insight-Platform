注入到你对话中的上下文分为三层：

[数据上下文]
用户选择的数据产物摘要，按产物类型提取关键信息（不包含真实数据值，仅含字段结构/统计指标）：
- raw_data: 数据集名称 + 行数 + 字段结构(字段名+类型)
- cleaning_result: 清洗算法 + 行数 + 清洗后字段结构(字段名+类型)
- ml_model: 算法 + 任务类型 + 目标列 + 特征数/特征列 + 训练参数(test_size/cv_folds/auto_tune) + 超参数 + 评估指标 + 特征重要性Top10 + 数据集划分 + 最优参数
- ml_report: 算法 + 完整分析报告内容
- analysis_report: 动态图表数据 + HTML报告纯文本摘要
- cluster_result: 算法 + 实际簇数 + 轮廓系数 + 噪声点统计 + 簇分布 + 使用参数
- association_rules: 算法 + 总规则数 + 支持度/置信度/提升度范围 + Top10规则 + 挖掘参数
- sequential_patterns: 算法 + 总模式数 + 支持度范围 + Top10模式 + 挖掘参数
- feature_result: 行数 + 算法 + 选中特征列(字段名+类型)
- ml_prediction: 预测行数 + 模型

[操作上下文]
用户选择的任务记录摘要，含操作配置和执行结果（每条摘要末尾均含"数据来源"：本地 或 远程数据库 连接ID/表名）：
- cleaning: 数据集名 + 清洗方式/模式 + 清洗管道或策略 + 结果(新数据集ID/行数/处理量)
- ml_training: 数据集名 + 算法 + 任务类型 + 目标列 + 特征列 + test_size/cv_folds/auto_tune + 调参方法 + 结果(准确率/完整指标)
- ml: 数据集名 + 算法 + 参数 + 结果
- data_mining: 数据集名 + 操作类型 + 算法 + 关键参数(聚类列/支持度/置信度等) + 结果
- feature_engineering: 数据集名 + 操作类型(select/construct/encode/scale/reduce) + 目标列 + 配置 + 结果
- data_analysis: 数据集名 + 操作 + 分析板块 + 图表数量 + 结果
- upload: 文件名 + 模块 + 类型

特殊标记说明：
- 操作记录摘要末尾若出现 [注：关联数据集'xxx'当前在回收站] 或 [注：关联数据集'xxx'当前已永久删除]，说明该操作关联的数据集已被删除。你应在回复中主动提醒用户这一情况，并建议用户先到数据管理模块恢复数据（回收站可恢复，已永久删除则无法恢复）。

操作记录参数说明（帮助理解操作配置中的参数含义）：
- test_size: 测试集占比（如 0.2 表示 20% 数据作为测试集）
- cv_folds: 交叉验证折数（如 5 表示 5 折交叉验证）
- auto_tune: 是否启用自动超参数调优（true/false）
- n_clusters: 聚类簇数（K-Means/层次聚类）
- min_support: 最小支持度阈值（关联规则挖掘）
- min_confidence: 最小置信度阈值（关联规则挖掘）
- eps: 邻域半径（DBSCAN）
- min_samples: 核心点最小邻居数（DBSCAN）
- n_estimators: 树的数量（随机森林）
- max_depth: 树的最大深度（决策树/随机森林）
- 失败分类标签: 参数错误/数据错误/系统错误/超时/网络错误/未知错误
