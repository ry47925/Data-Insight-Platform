# AI 分析

AI 分析模块让您以**自然语言对话**的方式与自己的数据交互。与普通聊天不同，您可以先"注入上下文"（选择真实的数据产物或操作记录），让 AI 基于您的实际数据回答，而不是凭空猜测。

## 一、上下文注入

页面顶部的"上下文注入"面板可选择两类上下文：

| 类型 | 内容 | 用途 |
| --- | --- | --- |
| **数据产物** | 原始数据、清洗产物、分析报告、挖掘产物、特征产物、机器学习产物 | 让 AI 基于真实数据回答（可预览摘要） |
| **操作记录** | 各模块的历史任务（清洗/分析/挖掘/特征/ML 的训练与预测） | 帮助诊断训练参数、清洗配置等问题 |

**筛选功能**：搜索框（按名称/#ID）、类型（数据产物/操作记录）、状态（成功/失败）、模块、数据来源（本地/远程）。

使用方法：勾选需要的上下文项 → 输入问题发送 → 本次对话将注入 N 个上下文项。

## 二、对话能力

- **多轮对话**：同一话题内 AI 记住上下文；"开始新话题"可断开历史关联。
- **追问建议**：AI 回答后会提供追问问题，一键续问。
- **Token 消耗**：每条消息展示输入/输出/合计 Token 用量。
- **缺失上下文提示**：问题需要数据但未注入时，AI 会提示缺失的类型，按提示补充即可。
- **快捷模板**：空会话提供 4 条常用提问（分析核心特征 / 数据质量 / 模型准确率 / 改进建议）。
- 快捷键：**Ctrl + Enter** 发送。

## 三、会话管理

- 历史会话自动保存，按更新时间排序，支持**搜索**、**打开**、**重命名**、**删除**。
- "新建会话"不会删除后端历史记录。

## 四、使用统计

右上角"使用统计"弹窗展示 4 个指标：今日 Tokens、本周 Tokens、累计 Tokens、今日调用次数。

## 五、使用建议

- **想得到精准分析**：先勾选相关数据产物（AI 基于真实数据回答），并明确说明想解决的问题。
- **想排查训练问题**：注入机器学习模块的操作记录，AI 可帮助解读训练参数、指标与潜在问题。
- **模块联动**：AI 分析可以与数据清洗、特征工程、机器学习的产物/记录结合提问，形成"分析-清洗-建模"闭环。
- 若顶部显示"AI 服务不可用"，说明系统尚未配置 API Key，请联系管理员配置。
